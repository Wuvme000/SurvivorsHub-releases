Survivors Hub

Your Azeroth Survivors,
all in one place

A free desktop app that keeps every run you play, turns your best runs into builds you can share, and keeps your add-ons up to date.

Run tracker · Build planner · Community builds · Mod and add-on manager

Download for Windows
Free · Windows 10 and 11 · Updates itself

Every run, saved

Map, difficulty, talents, spells, jewelry, gear and damage over time. See your best runs per map and compare two side by side.

Build planner with real runs

Turn a good run into a build, with the run as proof. Publish it to the community, and browse and save the builds other players made for every class and spec.

Mods and add-ons kept up to date

Drop in an add-on's zip and it's set up right, folder names and all. Updates come straight from each author's own page.

Game updates

The game's patch notes and your add-ons' release notes, in one list.

Share any run

Turn a run into a picture card with its spells and ranks, gear, jewelry and all three talent trees. Copy it and paste it straight into Discord.

Or make it a build: the run comes along as proof, so other players can see it really worked.

Safe for your game

  • Never changes the game program or your save.
  • Only writes inside the game's AddOns folder and its own app folder.
  • Runs are recorded by a small add-on that only takes notes. It adds no windows or buttons and changes nothing.
  • No account needed. Only what you choose to share, like a build you publish, leaves your PC.

Install

  1. Download the installer above and run it.
  2. The Hub finds your game folder on its own (or pick it in Settings).
  3. On the Runs tab, click Turn it on to start recording runs.
If Windows shows "Windows protected your PC", click More info, then Run anyway (see the pictures below).

The first time you open it

Windows shows a warning for new apps it hasn't seen many people download yet. It isn't saying anything is wrong: the Hub is free and doesn't have a paid publisher certificate. It only shows once, never for updates.
